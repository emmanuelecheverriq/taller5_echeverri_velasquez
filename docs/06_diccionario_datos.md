# 6. Diccionario de datos

Motor: PostgreSQL. Esquema `paros` (negocio) y esquema `privado` (identidad). Las llaves primarias de las tablas con `id_*` son autoincrementales (`GENERATED BY DEFAULT AS IDENTITY`), salvo `codigo_paro` y `equivalencia_subcodigo`.


## paros.maquina

Linea de envasado de vinilos.

| Columna | Tipo | Longitud / precision | Nulo | Valor por defecto | Restricciones | Descripcion de negocio |
|---|---|---|---|---|---|---|
| id_maquina | SMALLINT | - | No | - | PK | Identificador interno de la maquina. |
| nombre | VARCHAR | 20 | No | - | UNIQUE | Nombre de la linea (Vinilos_1 a Vinilos_4). |
| activa | BOOLEAN | - | No | TRUE | - | TRUE si la maquina sigue en operacion. |

## paros.turno

Franja de trabajo en que se registra la produccion.

| Columna | Tipo | Longitud / precision | Nulo | Valor por defecto | Restricciones | Descripcion de negocio |
|---|---|---|---|---|---|---|
| id_turno | SMALLINT | - | No | - | PK | Identificador del turno. |
| nombre | VARCHAR | 30 | No | - | UNIQUE | Nombre normalizado del turno; incluye SIN ESPECIFICAR para datos historicos sin turno. |
| hora_inicio | TIME | - | Si | - | CHECK hora_inicio y hora_fin ambas NULL o ambas con valor | Hora en que empieza la jornada (NULL si no se conoce). |
| hora_fin | TIME | - | Si | - | - | Hora en que termina la jornada (NULL si no se conoce). |

## paros.area_impacto

Area de la empresa a la que impacta un codigo de paro.

| Columna | Tipo | Longitud / precision | Nulo | Valor por defecto | Restricciones | Descripcion de negocio |
|---|---|---|---|---|---|---|
| id_area | SMALLINT | - | No | - | PK | Identificador del area. |
| nombre | VARCHAR | 40 | No | - | UNIQUE | Mantenimiento, Produccion, Calidad, Almacen de materias primas o Paro programado. |

## paros.codigo_paro

Catalogo de causas de paro (codigos 01 a 18 del P-MTO-22).

| Columna | Tipo | Longitud / precision | Nulo | Valor por defecto | Restricciones | Descripcion de negocio |
|---|---|---|---|---|---|---|
| id_codigo_paro | SMALLINT | - | No | - | PK; CHECK entre 1 y 99 | Numero del codigo de paro (es la llave de negocio, no autoincremental). |
| nombre | VARCHAR | 100 | No | - | UNIQUE | Descripcion oficial del codigo. |
| id_area | SMALLINT | - | Si | - | FK -> area_impacto(id_area) ON DELETE RESTRICT ON UPDATE CASCADE | Area de impacto; NULL para el codigo 18, que no esta en la tabla del Excel. |

## paros.subcodigo_paro

Sistemas y componentes de la maquina que detallan los codigos 01, 03 y 05.

| Columna | Tipo | Longitud / precision | Nulo | Valor por defecto | Restricciones | Descripcion de negocio |
|---|---|---|---|---|---|---|
| id_subcodigo | SMALLINT | - | No | - | PK | Identificador del subcodigo. |
| id_codigo_paro | SMALLINT | - | No | - | FK -> codigo_paro(id_codigo_paro) ON DELETE RESTRICT ON UPDATE CASCADE | Codigo de paro al que pertenece. |
| codigo_sub | VARCHAR | 10 | No | - | UNIQUE (id_codigo_paro, codigo_sub) | Codigo jerarquico, por ejemplo 1.2.B. |
| descripcion | VARCHAR | 100 | No | - | - | Nombre del sistema o componente. |
| id_subcodigo_padre | SMALLINT | - | Si | - | FK -> subcodigo_paro(id_subcodigo) ON DELETE RESTRICT ON UPDATE CASCADE | Sistema al que pertenece un componente (NULL en nivel 1). |
| nivel | SMALLINT | - | No | - | CHECK nivel IN (1,2) y coherente con el padre | 1 = sistema, 2 = componente. |

## paros.equivalencia_subcodigo

Tabla de homologacion de la migracion: texto escrito en el Excel y subcodigo canonico.

| Columna | Tipo | Longitud / precision | Nulo | Valor por defecto | Restricciones | Descripcion de negocio |
|---|---|---|---|---|---|---|
| texto_origen | VARCHAR | 120 | No | - | PK | Texto exacto escrito en el Excel (65 variantes). |
| id_subcodigo | SMALLINT | - | No | - | FK -> subcodigo_paro(id_subcodigo) ON DELETE CASCADE ON UPDATE CASCADE | Subcodigo canonico al que equivale. |

## paros.motivo_parada

Catalogo de motivos de parada de maquina (campo Tipo de paro del Excel).

| Columna | Tipo | Longitud / precision | Nulo | Valor por defecto | Restricciones | Descripcion de negocio |
|---|---|---|---|---|---|---|
| id_motivo | SMALLINT | - | No | - | PK | Identificador del motivo. |
| sistema_codificacion | VARCHAR | 10 | No | - | UNIQUE (sistema_codificacion, codigo); CHECK IN ('ANTERIOR','ACTUAL') | ANTERIOR (2022-2023) o ACTUAL (desde 2024). |
| codigo | SMALLINT | - | No | - | UNIQUE (sistema_codificacion, codigo); CHECK > 0 | Numero del motivo dentro de su sistema de codificacion. |
| nombre | VARCHAR | 120 | No | - | - | Texto del motivo. |

## paros.registro_produccion

Registro de produccion de una maquina en un turno para una referencia (fila principal del formato hora a hora).

| Columna | Tipo | Longitud / precision | Nulo | Valor por defecto | Restricciones | Descripcion de negocio |
|---|---|---|---|---|---|---|
| id_registro | INTEGER | - | No | - | PK | Identificador del registro. |
| fecha | DATE | - | No | - | UNIQUE (fecha, id_maquina, id_turno, secuencia); CHECK >= 2020-01-01 | Dia del registro. |
| id_maquina | SMALLINT | - | No | - | FK -> maquina(id_maquina) ON DELETE RESTRICT ON UPDATE CASCADE; UNIQUE (fecha, id_maquina, id_turno, secuencia) | Maquina que produjo. |
| id_turno | SMALLINT | - | No | - | FK -> turno(id_turno) ON DELETE RESTRICT ON UPDATE CASCADE; UNIQUE (fecha, id_maquina, id_turno, secuencia) | Turno en que se produjo. |
| secuencia | SMALLINT | - | No | 1 | UNIQUE (fecha, id_maquina, id_turno, secuencia); CHECK >= 1 | Numero del registro dentro del mismo dia, maquina y turno (1, 2, ...). |
| id_persona | SMALLINT | - | Si | - | FK -> persona(id_persona) ON DELETE SET NULL ON UPDATE CASCADE | Operaria/o; NULL si no se anoto. |
| id_referencia | SMALLINT | - | Si | - | FK -> referencia(id_referencia) ON DELETE RESTRICT ON UPDATE CASCADE | Producto envasado; NULL si no se anoto. |
| pacas_producidas | INTEGER | - | No | 0 | CHECK >= 0 | Pacas producidas en el registro. |
| horas_trabajadas | NUMERIC | 5,2 | No | 0 | CHECK entre 0 y 24 | Horas en que la maquina estuvo programada para producir. |
| es_sintetico | BOOLEAN | - | No | FALSE | CHECK: si es TRUE, pacas = 0 y horas = 0 | TRUE si se creo en la migracion para conservar paros sin registro principal. |
| observaciones | VARCHAR | 500 | Si | - | - | Comentarios de la operaria (sin nombres de personas). |

## paros.paro

Tiempo perdido por un codigo de paro (y subcodigo) dentro de un registro.

| Columna | Tipo | Longitud / precision | Nulo | Valor por defecto | Restricciones | Descripcion de negocio |
|---|---|---|---|---|---|---|
| id_paro | INTEGER | - | No | - | PK | Identificador del paro. |
| id_registro | INTEGER | - | No | - | FK -> registro_produccion(id_registro) ON DELETE CASCADE ON UPDATE CASCADE | Registro al que pertenece. |
| id_codigo_paro | SMALLINT | - | No | - | FK -> codigo_paro(id_codigo_paro) ON DELETE RESTRICT ON UPDATE CASCADE | Causa del paro. |
| id_subcodigo | SMALLINT | - | Si | - | FK compuesta (id_subcodigo, id_codigo_paro) -> subcodigo_paro ON DELETE RESTRICT ON UPDATE CASCADE | Sistema o componente afectado (solo codigos 01, 03, 05). |
| minutos | NUMERIC | 7,2 | No | - | CHECK > 0 y <= 1440 | Duracion del paro en minutos. |
| equipo_ejecutor | VARCHAR | 13 | Si | - | CHECK NULL o IN ('OPERARIOS','MANTENIMIENTO') | Quien hizo el ajuste: OPERARIOS o MANTENIMIENTO (solo codigo 05). |
| id_persona | SMALLINT | - | Si | - | FK -> persona(id_persona) ON DELETE SET NULL ON UPDATE CASCADE | Persona involucrada (seudonimo). |

| id_maquina | SMALLINT | - | No | - | FK -> maquina(id_maquina) ON DELETE RESTRICT ON UPDATE CASCADE | Maquina detenida. |

| horas_no_trabajadas | NUMERIC | 5,2 | No | - | CHECK > 0 y <= 48 | Horas sin trabajar. |
| observacion | VARCHAR | 200 | Si | - | - | Detalle escrito por mantenimiento/produccion. |
